# Triage Labels

技能以五个规范 triage 角色说话，本文件把角色映射到本仓库 issue tracker 实际使用的标签字符串。

| 技能中的角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已充分描述，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不处理 |

技能提到某个角色（如"打 AFK-ready 标签"）时，使用本表右列对应的标签字符串。

如需改用仓库既有的其他标签命名，直接编辑右列。
