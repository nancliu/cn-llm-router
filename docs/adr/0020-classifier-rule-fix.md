# ADR-0020：分类规则回归修复（agent-high-3 / ld-low-5）

- 状态：accepted
- 日期：2026-09-30
- 关联：ADR-0002（分类器）、ADR-0018（双模型分流）

## 背景

ADR-0018 混合链全量 180 题实测（2026-09-29）残留 2 题类别错误：
- `agent-high-3`「为这个自动化流程设计状态机，处理分支与回退」期望 Agent编排/高——当时 CED 误判程序编码；
- `ld-low-5`「给这本技术书籍写个一句话推荐语」期望 长文档处理/低——当时 CED 误判创意生成。

2026-09-30 复现（probe4，Qwen 与 CED 单链）确认：
- ld-low-5：**两模型均判创意生成**（Qwen 0.98 / CED 0.95 高置信，second_guess 均为文书撰写而非长文档处理）；
- agent-high-3：CED 类别已对（Agent编排）但复杂度波动（Qwen 曾在"中"与"高"间波动），需要向"高"收敛。

## 决策

仅修改 `classifier._build_prompt` 的判定规则文本（主链与快速链共享，行为不改架构）：

1. **类别规则新增**："给【指定文档】（书籍/论文/报告/手册/合同）写推荐语/摘要/一句话评论/概述时，即使产出是简短文案，也按文档对象归长文档处理；未指定文档对象的纯文案/点子 → 创意生成"——解决"文档对象 vs 创意外壳"的判别歧义。
2. **复杂度规则增强**："设计状态机/流程编排、处理分支/回退/异常路径也属高（系统性设计+边界条件）"——把 状态机+分支回退 显式映射到"高"，收敛 Qwen 的中/高波动。

不改：降级链顺序、缓存键、双模型分流逻辑、任何评分数据。

## 验证（2026-09-30 实测）

| 项 | 修复前 | 修复后 | 报告 |
|---|---|---|---|
| Qwen 端到端（180 题） | 179/180 = 99.44% | **180/180 = 100.0%**（12 类全部 15/15，无回归） | `reports/eval-qwen-fix-20260930.json` |
| ld-low-5（Qwen 单链） | 创意生成 ❌ | 长文档处理/低 ✅ | probe5 |
| ld-low-5（CED 单链） | 创意生成 ❌ | 长文档处理/低 ✅ | probe6 |
| agent-high-3（Qwen 单链） | 类别对/复杂度中-高波动 | Agent编排/高 ✅ | probe5 |

`EVAL_BASELINE`（ADR-0013 门禁）中 Qwen3.8-Max-0902 由 0.994 更新为 1.0（来源本 ADR 报告）。
复杂度整体命中率非本次目标（仍 77.8% 左右），另行跟踪。

## 影响

- 分类器 prompt 规则增强，对"文档对象文案"与"状态机/流程编排"类请求的判类更稳；
- 双链（Qwen 主链 / CED 快速链）共用新规则，两链同步受益；
- README 状态行的默认分类模型准确率数字同步更新为 100%（180/180）。
