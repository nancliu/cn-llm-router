# ADR-0004：路由层数据源与计算边界（data/*.csv 为唯一真相源）

- 状态：accepted
- 日期：2026-09-23
- 关联：ADR-0001、ADR-0002

## 决策

路由层（分类器与选择器）**只消费 `data/*.csv`**：`models.csv`（模型注册表）、`scores.csv`（长表：category × complexity × model × score）、`weights.csv`（任务 × 维度权重）。主选/备选/理由由**代码现算**（依据 ADR-0001 的公式与策略档位），**不读取飞书表格里已预计算的推荐区**。

## 为什么

- 可测试：推荐算法进代码后可用单元测试锁定口径，表格公式无法进 CI；
- 口径统一：代码只认 ADR-0001 的算法，不会因表格被人工改动而漂移；
- 可复现：data/*.csv 进仓库（含 as_of 版本列），任何时间 clone 都能复算出打分表 v1 的结论。

## 备选

- **读飞书表格预计算推荐**：省去重实现，但代码依赖在线表格、口径不可测试、表格一改代码就静默漂移。
- **飞书自动同步脚本**：留作 backlog（v1 手工导出一次进仓库）。

## 影响

- 数据版本：每份 CSV 带 `as_of` 列，`data/VERSION` 标识当前数据版本；
- 飞书表格定位为"人工维护与展示界面"，不是代码的运行时依赖。
