# ADR-0003：网关自建 OpenAI 兼容薄层，预留 LiteLLM

- 状态：accepted
- 日期：2026-09-23
- 关联：ADR-0001、ADR-0002

## 决策

统一网关在 v1 用**自建薄层**：只做 逻辑模型名 → {base_url, 上游模型名, key} 的映射、OpenAI 兼容协议转发、失败切备选。对外接口按 OpenAI 兼容设计（客户端可替换 `base_url` 接入）。不默认集成 LiteLLM。

## 为什么

- 依赖少、代码透明，符合开源项目被社区审查的需求；
- 项目核心差异化在"分类 × 评分矩阵"，网关不是卖点，薄层足够；
- 需要预算管控 / 多厂商高级路由时，再接 LiteLLM 作为可选 provider（接口预留）。

## 备选

- **LiteLLM**：成熟（100+ 厂商、预算/负载均衡），但引入大依赖与配置复杂度，v1 不需要。

## 影响

- 模型名映射表独立配置（providers 配置），仓库零密钥。
